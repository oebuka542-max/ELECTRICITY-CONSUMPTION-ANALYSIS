# ELECTRICITY-CONSUMPTION-ANALYSIS
An exploratory data analysis project examining electricity consumption patterns across three power distribution zones using 2017 electricity consumption data. The project uses Microsoft Excel to investigate hourly, weekly, and monthly consumption trends, compare electricity demand across zones, and explore relationships between electricity consumption and weather variables such as temperature, humidity, and wind speed.  The analysis identifies peak consumption periods, differences in demand across zones, and weather-related consumption patterns to generate meaningful insights that can support energy planning and decision-making.
